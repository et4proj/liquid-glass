## API 速查

```ts
// react 绑定层（packages/react）
import { GlassProvider, GlassSurface, useGlass, useGlassSurface } from '@et4proj/liquid-glass-react'
<GlassProvider config={cfg} probe={p} backends={b}>  // probe/backends 缺省 web 探针 + [svg, css]
  <GlassSurface as="nav" role="bar" shape={{ kind: 'capsule' }}>…</GlassSurface>
</GlassProvider>
const glass = useGlass()                    // GlassRuntime | null（Provider render 期惰性创建，首帧即有值）
const { ref, id } = useGlassSurface(decl, externalRef?)  // ref 回调注册/注销；声明变化 → unregister + re-register

// adapter 体系（packages/adapter + 数据包）
import { applyAdapter } from '@et4proj/liquid-glass-adapter'
import { antdMobileAdapter } from '@et4proj/liquid-glass-adapter-antd-mobile'
const handle = applyAdapter(runtime, antdMobileAdapter)  // detect 不通过 → no-op + dev warn
handle.dispose()                                         // 注销发现 + 引用计数归零移除注入样式

// web 选择器发现（adapter 的底层机制，也可直接使用）
import { mountSelectorDiscovery } from '@et4proj/liquid-glass-web'
mountSelectorDiscovery(runtime, { surfaces: [{ selector: '.adm-tab-bar', declaration: { role: 'bar' } }], root })
```

## 挂载协议（playground-federation-design §4 落地形态）

```ts
// playground/ant-design-mobile/src/remote.tsx —— 唯一远程出口（exposes './app'）
export function mount(el: HTMLElement, ctx: DemoHostContext): void; // ctx.runtime = host runtime
export function unmount(): void; // root.unmount + detachAdapter
```

- dev 编排：host `pnpm --filter @et4proj/liquid-glass-playground dev`（5173）+ remote `pnpm --filter @et4proj/liquid-glass-playground-antd-mobile dev`（5174），playground 演示中心自动挂载；remote 未启动时面板给出启动指引与重试按钮。
- react-refresh 前导：host 侧 `react-preamble.ts` 先于 remote 模块链就绪（决定表 #20）；挂载 catch **必须浮出真实错误**——曾空吞错让"server 没起"的猜测掩盖 MF Runtime #RUNTIME-001（调试踩坑，已修复）。
- HMR 边界：remote 改码需在 host 重挂载（切换/重试）后可见（内部工具接受，联邦化文档 §6 已标注）。
- 浏览器级验收（2026-10-17）：standalone 5174 + host 5173 演示中心均渲染正常、console 干净；交互终验数值与校准表精确吻合——ios27↔ios26 切换（blur 6px↔16px、refraction 0.7↔0.5、tint 0.08↔0.18）、强度 0.1（blur 2.8px = subtle 锚点 2 的线性插值理论值、refraction 0.42）、antd Switch 点击选中态切换（aria-checked 同步）。
